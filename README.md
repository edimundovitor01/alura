Crie um site completo, moderno e responsivo sobre "Curiosidades de Video Games" 
que será hospedado no GitHub Pages. O site deve conter:

ESTRUTURA:
- Página inicial (index.html) com hero section atrativa
- Seção de curiosidades em formato de cards
- Filtro por categoria (Nintendo, PlayStation, Xbox, PC, Arcade, Retro)
- Modal/popup ao clicar em cada curiosidade com detalhes
- Footer com links sociais e créditos

TECNOLOGIAS:
- HTML5 semântico
- CSS3 com variáveis, Flexbox e Grid
- JavaScript vanilla (sem frameworks)
- Design responsivo (mobile-first)
- Tema dark/light toggle
- Animações suaves com CSS transitions

CONTEÚDO (mínimo 20 curiosidades reais e verificadas), exemplos:
- O Nintendo Entertainment System foi lançado no Brasil oficialmente só em 1993
- O personagem Mario originalmente se chamava "Jumpman"
- Pac-Man foi inspirado em uma pizza com uma fatia faltando
- O primeiro easter egg da história dos games foi em Adventure (Atari, 1979)
- PlayStation era originalmente um projeto da Nintendo com a Sony

ARQUIVOS NECESSÁRIOS:
1. index.html
2. style.css
3. script.js
4. README.md com instruções de deploy no GitHub Pages
5. .gitignore

DESIGN:
- Paleta: roxo neon (#8b5cf6), ciano (#06b6d4) e dark (#0f0f23)
- Fonte: 'Poppins' ou 'Inter' do Google Fonts
- Ícones: Font Awesome ou emojis
- Efeito glassmorphism nos cards
- Hover effects com glow neon

DEPLOY:
